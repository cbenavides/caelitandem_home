🟢 Proyecto entregado Migración y Core Financiero

Sistema de Recaudación para Servicio de Agua Potable V2.0

Refactorización completa del software de recaudación local. Se migró la arquitectura original de PHP 5.5 a PHP 7.4/8, MariaDB se particionó la base de datos de cobro a tablas activas e históricas (200,000+ registros), garantizando paridad financiera y controles de recargos.

🔧 Tecnologías: PHP 7.4, MariaDB (Split de Tablas), Vanilla JS/jQuery, CSS Premium, Apache.
📈 Resultados: 100% de paridad de saldos en migración, generación de reportes de cartera instantánea y automatización del apagado seguro por UPS.
🔵 Prospecto activo Comercio Local & Región

Portal de Productores y Cooperativas de la Mixteca

Diseño y desarrollo de una plataforma web progresiva orientada a conectar a pequeños agricultores, productores de artesanías y cooperativas locales de la Mixteca con mercados estatales y nacionales, eliminando intermediarios.

🔧 Tecnologías: Next.js (React), Tailwind CSS, Node.js (REST API), PostgreSQL, PWA.
📈 Resultados: Catálogo auto-administrable con geolocalización, carga ultra-rápida offline para zonas rurales, y cobros vía SPEI.
🟡 En análisis Modernización Legada

Migración de Hojas de Excel a Panel Web Multiusuario

Conversión de sistemas manuales e inventarios dispersos en archivos de Excel o Access a un panel administrativo centralizado en la nube. Permite el control multiusuario simultáneo y registro histórico seguro.

🔧 Tecnologías: MariaDB, Node.js Express, HTML5 semántico, Nginx Proxy, Docker.
📈 Resultados: Eliminación total de archivos corruptos, historial de auditoría de modificaciones de usuarios y alertas de stock mínimo automáticas.
