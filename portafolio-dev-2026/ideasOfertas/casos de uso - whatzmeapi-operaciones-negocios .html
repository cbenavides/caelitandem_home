🛠️ 2. Arquitectura de Solución Híbrida (IA + WhatsApp)

Integración de alto rendimiento a fracción de costo corporativo combinando WhatzmeAPI, n8n, modelos de IA y Chatwoot [cite: 423].

[Cliente en WhatsApp] 
        │
        ▼ (Mensaje / PDF)
 [WhatzmeAPI (QR)] ──── Webhook ────► [n8n Orquestador]
                                          │
                        ┌─────────────────┴─────────────────┐
                        ▼                                   ▼
          [Análisis Semántico PDF]             [Chatwoot (Mesa de Ayuda)]
         (DeepSeek / Gemini Vision)             (Agente Humano + Handoff)

Componentes Clave del Stack

Componente Rol en la Solución Ventaja Técnica
WhatzmeAPI Pasarela API de WhatsApp vía código QR [cite: 424]. Sin trámites rígidos de verificación corporativa Meta ni plantillas aprobadas [cite: 442].
n8n Orquestador de flujos y Webhooks [cite: 425, 468]. Procesamiento asíncrono, descargas de PDF y conexión directa a bases de datos/POS [cite: 425, 468].
Gemini / DeepSeek Motor Multimodal y OCR Semántico [cite: 426, 469]. Extracción estructurada en JSON de textos, recetas o fotos de productos [cite: 426, 469].
Chatwoot Bandeja de Entrada Omnicanal Híbrida [cite: 427, 470]. Atención humana directa e interrupción limpia del bot en excepciones (Handoff) [cite: 427, 436, 437, 438].

⚠️ El Problema de Wayland (Ubuntu 26)

  • Bloqueo del portapapeles compartido bidireccional [cite: 140, 141].
  • Fallas en captura/grabación de pantalla para artefactos [cite: 142, 143].
  • Interceptación de clics/teclado de subagentes por seguridad [cite: 144].
  • Solución: Forzar el uso de Xorg (X11) [cite: 137, 146].

🛠️ Solución Definitiva Xorg (X11) en Ubuntu

Editar el archivo de configuración de GDM3 y descomentar/insertar la línea `WaylandEnable=false` [cite: 161, 164, 165]:

sudo nano /etc/gdm3/custom.conf

# Dentro del bloque [daemon], asegurar:
[daemon]
WaylandEnable=false

# Para evitar parches locales, enmascarar el socket a nivel de usuario:
systemctl --user mask wayland-session.service
sudo reboot

📦 Instalación Correcta de Paquetes `.tar.gz` en `/opt`

# 1. Crear directorios limpios
sudo mkdir -p /opt/google-antigravity-manager
sudo mkdir -p /opt/google-antigravity-ide

# 2. Extraer paquetes portables
sudo tar -xzf Antigravity.tar.gz -C /opt/google-antigravity-manager --strip-components=1
sudo tar -xzf Antigravity-IDE.tar.gz -C /opt/google-antigravity-ide --strip-components=1

# 3. Permisos de ejecución masivos y Enlaces simbólicos globales
sudo chmod -R +x /opt/google-antigravity-manager
sudo chmod -R +x /opt/google-antigravity-ide

sudo ln -sf /opt/google-antigravity-manager/antigravity /usr/local/bin/antigravity
sudo ln -sf /opt/google-antigravity-ide/antigravity-ide /usr/local/bin/antigravity-ide

🖥️ Creación de Lanzadores `.desktop` en Gnome

# Lanzador Manager
sudo bash -c 'cat < /usr/share/applications/antigravity.desktop

🔧 Solución de Errores Comunes

  • Error `V8 Version mismatch` (Electron): Ocurre por desajustes en el snapshot de JavaScript [cite: 1336, 1337, 1338]. Ejecutar con la bandera `--disable-gpu` o borrar caché en `~/.config/Antigravity` [cite: 70, 1341, 1344].
  • Portapapeles en VirtualBox 7: Asegurar pertenencia al grupo `vboxsf` (`sudo usermod -aG vboxsf $USER`) [cite: 274, 281] e inyectar el comando de auto-arranque `VBoxClient --clipboard` en Aplicaciones de Inicio de Ubuntu [cite: 278, 1391, 1397].
  • Open VSX Marketplace: Configurar en `/opt/google-antigravity-ide/resources/app/product.json` la propiedad `"serviceUrl": "https://open-vsx.org/vscode/gallery"` [cite: 323, 325, 326].

☁️ 4. Infraestructura Cloud: Oracle OCI vs. Hostinger

💎 Servidor Oracle OCI Ampere A1 Flex (Evaluación Técnica)

Configuración: 4 OCPUs (ARM64 Ampere Neoverse-N1), 24 GB RAM, 4 Gbps Red [cite: 775, 811, 812].

🛡️ Estatus de Suscripción Universal Credits (PAYG)

Al contar con la suscripción Universal Credits activa ($0.00 compromiso) [cite: 961, 964]:

  • Protección contra recortado: Mantiene los 4 núcleos y 24 GB RAM intactos [cite: 817, 965].
  • Sin riesgo de Idle Reclaim: Oracle no borra la VM por inactividad [cite: 822, 851, 972].
  • El banner de alerta en OCI es genérico y no afecta cuentas de pago/PAYG [cite: 967, 969, 970, 971].

💾 Manejo del Almacenamiento (Storage)

  • Límite Gratis Global: 200 GB totales en la cuenta [cite: 831, 985].
  • Acción recomendada: Ampliar el Boot Volume de 45 GB a 100 GB - 150 GB [cite: 830, 954, 988].
  • Costo: $0.00 MXN mientras la suma total no supere 200 GB [cite: 831, 983, 989].

📨 Dimensionamiento para WhatsApp Cloud API (60,000 msgs/mes)

60,000 mensajes al mes generan ~2,000 msgs/día, pero con picos masivos de Webhooks concurrentes [cite: 742]. La instancia de Oracle de 24 GB RAM y 4 Cores permite ejecutar bases de datos en caché (Redis/PostgreSQL), Nginx Proxy Manager y contenedores Docker para absorber estos picos sin latencia [cite: 834, 876].
