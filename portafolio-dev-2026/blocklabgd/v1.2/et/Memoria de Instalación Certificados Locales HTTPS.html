📜 3. Bitácora de Comandos Ejecutados

3.1. Descarga e Instalación de mkcert

Se descargó el binario compilado de mkcert y se configuró como ejecutable en el servidor:

wget -O /home/carlos/GitHub/caelitandem_home/restaurantb/contenedor/mkcert https://github.com/FiloSottile/mkcert/releases/download/v1.4.4/mkcert-v1.4.4-linux-amd64
chmod +x /home/carlos/GitHub/caelitandem_home/restaurantb/contenedor/mkcert

3.2. Creación de la Autoridad Certificadora (CA)

Se generó la CA local en la carpeta del usuario `carlos`:

/home/carlos/GitHub/caelitandem_home/restaurantb/contenedor/mkcert -install

Este paso generó la clave privada y pública de la CA en /home/carlos/.local/share/mkcert/.

3.3. Corrección de Permisos en la Carpeta SSL

Dado que la carpeta del volumen de host ssl/ fue creada por el servicio Docker como root, se ejecutó un contenedor temporal Alpine para restablecer el propietario a UID/GID 1000 (carlos):

docker run --rm -v /home/carlos/GitHub/caelitandem_home/restaurantb/ssl:/ssl alpine chown -R 1000:1000 /ssl

3.4. Generación de los Certificados Firmados

/home/carlos/GitHub/caelitandem_home/restaurantb/contenedor/mkcert -cert-file /home/carlos/GitHub/caelitandem_home/restaurantb/ssl/server.crt -key-file /home/carlos/GitHub/caelitandem_home/restaurantb/ssl/server.key 192.168.1.71 localhost 127.0.0.1

3.5. Exposición Pública de la CA y Reinicio de Apache

Se copió el archivo de la CA raíz pública como ca.crt al DocumentRoot de la web para su distribución por red local, y se reinició el contenedor de Apache:

cp /home/carlos/.local/share/mkcert/rootCA.pem /home/carlos/GitHub/caelitandem_home/restaurantb/www/ca.crt
docker compose -f /home/carlos/GitHub/caelitandem_home/restaurantb/contenedor/docker-compose.yml --project-directory /home/carlos/GitHub/caelitandem_home/restaurantb/contenedor restart web

📱 4. Procedimiento de Instalación en Dispositivos Android

Paso 1: Descargar la CA Raíz

Conecte el dispositivo Android a la red Wi-Fi local del laeshe.

Abra el navegador Google Chrome y visite la siguiente dirección IP para descargar el archivo de la CA:

http://192.168.1.71:6001/ca.crt

Confirme la descarga del archivo ca.crt en su dispositivo.

Paso 2: Registrar en el Almacenamiento

Vaya a los Ajustes o Configuración de Android.

  1. Seleccione la opción Certificado de CA.
  2. Busque en su almacenamiento interno y seleccione el archivo ca.crt descargado.
  3. Asigne un nombre descriptivo al certificado (ej: CA Local LAESH) y pulse aceptar.

💻 5. Procedimiento de Instalación en Computadoras y Laptops (Clientes en LAN)

🪟 En Laptops con Windows

  1. Descarga la CA desde la laptop cliente ingresando a:
    http://192.168.1.71:6001/ca.crt.
  2. Haz doble clic sobre el archivo ca.crt descargado y pulsa "Instalar certificado...".
  3. Elige "Usuario actual" y haz clic en Siguiente.
  4. Selecciona la opción "Colocar todos los certificados en el siguiente almacén".

🍎 En Laptops con macOS

  1. Descarga la CA desde la Mac en:
    http://192.168.1.71:6001/ca.crt.
  2. Haz doble clic sobre ca.crt para abrir el gestor de Acceso a Llaveros (Keychain Access).
  3. Arrastra el certificado a la categoría Certificados del llavero Inicio de sesión (login) o Sistema.
  1. Descarga la CA en tu máquina: wget http://192.168.1.71:6001/ca.crt

🔒 6. Reparación del Controluser de phpMyAdmin (Fix Adicional)

Durante la estabilización, se auditó un fallo recurrente de conexión del usuario de control en phpMyAdmin (mysqli::real_connect(): Access denied for user 'pma'@'172.19.0.2').

Causa Raíz

Acción Correctiva Ejecutada

docker exec -i laesh_db mariadb -u root -pcomite_2026 -e "
  CREATE USER IF NOT EXISTS 'pma'@'%' IDENTIFIED BY 'pma_pass_2026';
  CREATE DATABASE IF NOT EXISTS \`phpmyadmin\` CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
  GRANT ALL PRIVILEGES ON \`phpmyadmin\`.* TO 'pma'@'%';
  GRANT SELECT ON \`mysql\`.* TO 'pma'@'%';
  FLUSH PRIVILEGES;
"
docker compose -f /home/carlos/GitHub/caelitandem_home/restaurantb/contenedor/docker-compose.yml --project-directory /home/carlos/GitHub/caelitandem_home/restaurantb/contenedor restart pma
