Propuesta Técnica: Blindaje contra Salidas y Recargas Accidentales en Portales Web LAESH

Investigación, análisis de riesgos de navegación en navegadores modernos y propuesta de solución arquitectónica multicapa portable (Desktop, Android, iOS Safari / Chrome) para los portales de Médicos, Recepción y Administración.

Versión v1.2 · Fase 1 / Fase 2
Fecha Septiembre 2026
Sistemas Afectados Médicos (md) · Recepción (rc) · Admin (admrc)
Compatibilidad Desktop · Android · iOS Safari · Chrome

1 Diagnóstico y Problemática Operativa

En el uso diario de los portales web de Médicos, Recepción (Laboratorio) y Administración, la salida o recarga involuntaria de una página activa genera interrupciones críticas en el flujo de trabajo clínico:

  • Pérdida de captura de datos: Órdenes médicas a medio llenar, notas clínicas de pacientes, selecciones del catálogo de estudios o parámetros de configuración del sistema.
  • Desconexión del canal en tiempo real: Caída intempestiva del WebSocket de baja latencia (Swoole v6 ws-client.js), lo cual interrumpe las alertas auditivas (whistle/chime), los avisos push de toma de muestras y la sincronización de estados concurrentes.
  • Desorientación y pérdida de estado UI: Reinicio de filtros aplicados en listados de órdenes, colapso de acordeones abiertos, pérdida de paginación y retrasos en la atención al paciente en mostrador.
Restricciones de Seguridad W3C en Navegadores Modernos:
Por normativas internacionales contra sitios maliciosos y técnicas de tab-hijacking (secuestro de pestañas), ningún navegador moderno permite a JavaScript impedir el cierre de una pestaña de manera invisible ni personalizar el texto del diálogo nativo de cierre. Además, la API beforeunload exige Transient User Activation (que el usuario haya interactuado con la página antes de que el diálogo se active). Por tanto, la solución requiere un enfoque multicapa que neutralice los eventos antes de que alcancen el ciclo de descarga del navegador.

2 Inventario Exhaustivo de Eventos de Salida Accidental

A partir de la auditoría técnica y los eventos reportados por los operadores clínicos, se ha consolidado la matriz completa de causas de salida o recarga involuntaria en Desktop y Dispositivos Móviles:

Plataforma Evento / Disparador Mecanismo Accidental Severidad Estrategia de Intercepción
Desktop F5 / Ctrl + F5 Pulsación accidental de tecla de recarga. Crítica Listener keydown con preventDefault() + Modal In-App LAESH.
Desktop Ctrl + R / Cmd + R (macOS) Atajo alternativo universal de recarga del navegador. Crítica Listener keydown con preventDefault() + Modal In-App LAESH.
Desktop Ctrl + Shift + R Recarga forzada saltando caché del navegador. Crítica Listener keydown (fase capture) + beforeunload guard.
Desktop Ctrl + W / Cmd + W Atajo de cierre inmediato de la pestaña activa. Crítica Guard universal W3C beforeunload (diálogo nativo).
Desktop Alt + F4 / Cmd + Q Cierre completo de la ventana del navegador o proceso. Crítica Guard universal W3C beforeunload (diálogo nativo).
Desktop Botones Atrás / Adelante del Browser Clic con el cursor en las flechas ← o → de la barra superior. Crítica Trampa de historial (history.pushState + evento popstate).
Desktop Alt + Flecha Izquierda Atajo de teclado del sistema operativo para retroceder página. Alta Trampa de historial (popstate) + bloqueo en keydown.
Desktop Botones Laterales de Ratón (Botón 3 y 4) Ratones ergonómicos con pulsadores de pulgar para Atrás/Adelante. Alta Captura de pointerdown / mouseup en botones 3 y 4.
Desktop Tecla Backspace fuera de foco Navegadores antiguos o configuraciones donde Backspace retrocede. Media Bloqueo en keydown si el foco no es un input/textarea.
Desktop Drag & Drop accidental en viewport Arrastrar un archivo o texto fuera de una zona válida reemplaza la URL. Media Bloqueo global de eventos dragover y drop en window.
Mobile Pull-to-refresh (Arrastre vertical) Deslizamiento táctil hacia abajo con scroll en el tope de página. Crítica CSS overscroll-behavior-y: contain + Fallback touchmove.
Mobile Botón Atrás del Dispositivo (<) Barra virtual de navegación de Android o botón físico del equipo. Crítica Trampa de historial con centinela artificial en popstate.
Mobile Gesto de Borde Lateral (Edge Swipe) Deslizar desde el borde izquierdo en iOS Safari o Android 10+. Crítica CSS overscroll-behavior-x: none + Trampa popstate.
Mobile Suspensión de Memoria (Tab Discarding) El sistema operativo purga la pestaña al cambiar a cámara o WhatsApp. Alta Resiliencia de sesión local (Borrador en sessionStorage).
Mobile / Ambos Tecla "Ir / Enter" en teclado virtual Pulsar Enter al capturar un campo dispara el submit nativo. Media Prevención de submit por omisión en formularios AJAX/HTMX.
Mobile / Ambos Toque involuntario en Logo o Breadcrumb El operador toca por accidente el enlace a inicio al intentar tocar un botón vecino. Media Confirmación in-app o enlace con confirmación si hay datos activos.

3 Propuesta de Solución: Arquitectura Multicapa

Para garantizar una cobertura de 360 grados sin impactar negativamente la fluidez ni el rendimiento, se implementa una arquitectura defensiva en cascada gobernada por un módulo ligero independiente: portal-guard.js.

    Inicio[Usuario interactúa con el Portal Médico/Recepción] --> Disparador{¿Qué acción se detectó?}
    
    Disparador -->|Arrastre táctil hacia abajo| C1[Capa 1: CSS Overscroll Lock]
    C1 -->|Bloqueo CSS nativo| R1[Cero recargas por pull-to-refresh]

Capa 1: Blindaje Táctil Anti Pull-to-Refresh y Anti-Overscroll (Mobile & Tablet)
Inhabilita la recarga por arrastre vertical y los gestos accidentales de navegación lateral en dispositivos táctiles.

Se aplica la propiedad estándar CSS en los contenedores raíz del portal médico y de recepción:

/* Aplicable al layout global de medicos.php y labadmin.php */
html, body.portal-body {
    overscroll-behavior-y: contain; /* Elimina el pull-to-refresh en Chrome Android y Safari iOS 16+ */
    overscroll-behavior-x: none;    /* Bloquea la navegación por deslizamiento de bordes laterales */
}

Fallback JavaScript (iOS Safari < 16): Para versiones previas de WebKit en iOS, se añade un listener no bloqueante sobre touchmove que evalúa si el scrollTop del scroll principal está en 0 y el vector del gesto es descendente (touches[0].clientY > startY), invocando e.preventDefault() únicamente en dicha condición de borde.

Capa 2: Trampa de Historial (History Guard / Anti-Atrás con popstate)
Intercepta el botón Atrás del sistema (Android), atajos de retroceso y gestos de swipe en iOS Safari.

1. Al iniciar la sesión o cargar la pantalla, se empuja un estado centinela al stack de navegación:

// Inyección del centinela de seguridad
history.pushState({ portalGuard: true }, document.title, window.location.href);

2. Al dispararse el evento popstate (cuando el usuario pulsa Atrás o desliza el borde), el centinela vuelve a empujarse inmediatamente para reponer la página actual, y se levanta un modal estilizado con el diseño de LAESH:

window.addEventListener('popstate', function(e) {
    // Restaurar inmediatamente el centinela en la pila de historial
    history.pushState({ portalGuard: true }, document.title, window.location.href);

    // Desplegar Modal UI LAESH
    PortalGuard.showConfirmModal({
        titulo: '¿Deseas salir del portal?',
        mensaje: 'Tienes una sesión de trabajo activa. Para salir de manera segura, utiliza el botón "Cerrar Sesión".',
        btnQuedarse: 'Permanecer en el portal',
        btnSalir: 'Salir de todos modos',
        onConfirmSalir: function() {
            PortalGuard.desactivar();
            window.location.href = '/laesh/?logout=1';
        }
    });
});
Capa 3: Interceptor de Teclado y Hardware de Ratón (Desktop)
Neutraliza las combinaciones comunes de recarga de página y los clics erráticos en botones laterales de ratones ergonómicos.
  • Captura de F5, Ctrl+R, Cmd+R: Interceptados en la fase de captura del evento keydown mediante e.preventDefault(), solicitando confirmación con el modal in-app antes de recargar.
  • Bloqueo de botones laterales de ratón (Botón 3 y 4): Los ratones de oficina con botones de navegación lateral en el pulgar son capturados en los eventos pointerdown y mouseup cuando e.button === 3 || e.button === 4, anulando la acción de retroceso del hardware.
  • Bloqueo de Backspace huérfano: Se verifica que la tecla Backspace solo funcione cuando el foco activo (document.activeElement) sea un elemento editable (input, textarea, contenteditable).
Capa 4: Guard Universal de Descarga (beforeunload estándar W3C)
El mecanismo de protección para el cierre de pestañas (Ctrl+W), clic en la "X" del navegador o ingreso de una nueva URL.

Se implementa bajo dos modalidades configurables:

  • Modo Continuo (Sesión Activa): Protege permanentemente las vistas de trabajo mientras el médico o recepcionista esté autenticado.
  • Modo Formulario Sucio (Dirty Form Tracker): Se activa dinámicamente cuando el operador introduce cambios en un formulario y aún no los ha enviado al servidor, complementando el tracker existente en el sistema.
window.addEventListener('beforeunload', function(e) {
    if (PortalGuard.debeAdvertir()) {
        e.preventDefault();
        e.returnValue = ''; // Requerido por la especificación W3C para forzar el diálogo nativo
        return '';
    }
});
Capa 5: Resiliencia de Sesión y Datos (Fallback Definitivo) Fase 2
Mecanismo de recuperación automática en caso de cierre forzoso, corte de energía o purgado de memoria RAM por el sistema operativo en móviles.
No incluir en la implementación, dejarlo para una fase 2.

Alcance técnico planificado para la Fase 2:

  • Auto-Guardado Local en Tiempo Real (Drafts): Almacenamiento continuo del estado de las órdenes y campos de texto en sessionStorage o localStorage conforme el usuario teclea.
  • Banner de Restauración Automática: Al reingresar tras una recarga forzada o crash de memoria, el sistema detecta el borrador huérfano y muestra: "Se detectaron datos no guardados de tu sesión previa. [Restaurar información] [Descartar]".
  • Reconexión Silenciosa de WebSockets: Restauración transparente de la sesión de Swoole v6 sin necesidad de recargar la página completa.

6 Especificación de Código: Módulo portal-guard.js

Estructura base del script autocontenido que se integrará en el ecosistema de assets de LAESH:

/**
 * ═══════════════════════════════════════════════════════════════════
 * portal-guard.js — LAESH Navigation & Accidental Unload Shield
 * ───────────────────────────────────────────────────────────────────
 * Blindaje multicapa contra salidas o recargas accidentales en
 * portales clínicos (Médicos y Recepción).
 * Compatible con Desktop, Android e iOS Safari/Chrome.
 * ═══════════════════════════════════════════════════════════════════
 */
(function(window, document) {
    'use strict';

    var PortalGuard = {
        enabled: true,
        bypass: false,
        sentinelState: { portalGuard: true },

        init: function() {
            if (!this.enabled) return;
            this.installHistoryTrap();
            this.installKeyboardGuard();
            this.installMouseGuard();
            this.installBeforeUnloadGuard();
            this.installTouchOverscrollFallback();
            this.injectModalUI();
        },

        // Capa 2: Trampa de Historial (popstate)
        installHistoryTrap: function() {
            var self = this;
            try {
                history.pushState(self.sentinelState, document.title, window.location.href);
            } catch(e) {}

            window.addEventListener('popstate', function(e) {
                if (self.bypass) return;
                try {
                    history.pushState(self.sentinelState, document.title, window.location.href);
                } catch(err) {}
                self.showModal(
                    '¿Deseas salir del portal?',
                    'Tienes una sesión activa de trabajo. Para salir del sistema, utiliza el botón oficial "Cerrar Sesión".',
                    function() { /* Permanece en la pantalla */ },
                    function() {
                        self.bypass = true;
                        window.location.href = '/laesh/?logout=1';
                    }
                );
            });
        },

        // Capa 3: Interceptor de Teclado (F5, Ctrl+R, Cmd+R, Backspace)
        installKeyboardGuard: function() {
            var self = this;
            window.addEventListener('keydown', function(e) {
                if (self.bypass) return;

                // F5 o Ctrl+R / Cmd+R
                var isF5 = (e.key === 'F5' || e.keyCode === 116);
                var isCtrlR = (e.ctrlKey || e.metaKey) && (e.key === 'r' || e.key === 'R' || e.keyCode === 82);
                
                if (isF5 || isCtrlR) {
                    e.preventDefault();
                    e.stopPropagation();
                    self.showModal(
                        '¿Recargar la página?',
                        'Si recargas la página, podrías perder cambios no guardados en los formularios activos.',
                        function() { /* Permanece */ },
                        function() {
                            self.bypass = true;
                            window.location.reload();
                        }
                    );
                    return false;
                }

                // Backspace fuera de campos editables
                if (e.key === 'Backspace' || e.keyCode === 8) {
                    var el = document.activeElement;
                    var isInput = el && (el.tagName === 'INPUT' || el.tagName === 'TEXTAREA' || el.isContentEditable);
                    if (!isInput) {
                        e.preventDefault();
                    }
                }
            }, true);
        },

        // Capa 3: Bloqueo de Botones Laterales de Ratón (3 y 4)
        installMouseGuard: function() {
            var self = this;
            window.addEventListener('pointerdown', function(e) {
                if (e.button === 3 || e.button === 4) {
                    e.preventDefault();
                    e.stopPropagation();
                }
            }, true);
        },

        // Capa 4: Guard Universal de Descarga (beforeunload)
        installBeforeUnloadGuard: function() {
            var self = this;
            window.addEventListener('beforeunload', function(e) {
                if (self.bypass) return;
                e.preventDefault();
                e.returnValue = '';
                return '';
            });
        },

        // Capa 1: Fallback táctil para iOS Safari legacy
        installTouchOverscrollFallback: function() {
            var startY = 0;
            window.addEventListener('touchstart', function(e) {
                if (e.touches.length === 1) startY = e.touches[0].clientY;
            }, { passive: true });

            window.addEventListener('touchmove', function(e) {
                if (e.touches.length === 1) {
                    var currentY = e.touches[0].clientY;
                    var isAtTop = (document.documentElement.scrollTop || document.body.scrollTop) === 0;
                    if (isAtTop && currentY > startY) {
                        if (getComputedStyle(document.body).overscrollBehaviorY === 'auto') {
                            e.preventDefault();
                        }
                    }
                }
            }, { passive: false });
        },

        // Modal de Interfaz Integrado
        injectModalUI: function() {
            if (document.getElementById('portal-guard-modal')) return;
            var html = 
                '<div id="portal-guard-modal" style="display:none; position:fixed; inset:0; z-index:999999; background:rgba(15,23,42,0.65); backdrop-filter:blur(4px); align-items:center; justify-content:center;">' +
                '  <div style="background:#fff; border-radius:12px; max-width:440px; width:90%; padding:24px; box-shadow:0 20px 25px -5px rgba(0,0,0,0.25); text-align:center; font-family:sans-serif;">' +
                '    <h3 id="pg-modal-title" style="margin:0 0 10px 0; color:#0052B7; font-size:1.25rem; font-weight:700;"></h3>' +
                '    <p id="pg-modal-msg" style="margin:0 0 20px 0; color:#475569; font-size:0.95rem; line-height:1.5;"></p>' +
                '    <div style="display:flex; gap:10px; justify-content:center;">' +
                '      <button id="pg-btn-stay" type="button" style="padding:10px 18px; border-radius:8px; border:none; background:#0052B7; color:#fff; font-weight:600; cursor:pointer;">Permanecer</button>' +
                '      <button id="pg-btn-exit" type="button" style="padding:10px 18px; border-radius:8px; border:1px solid #cbd5e1; background:#f8fafc; color:#64748b; font-weight:600; cursor:pointer;">Salir</button>' +
                '    </div>' +
                '  </div>' +
                '</div>';
            document.body.insertAdjacentHTML('beforeend', html);
        },

        showModal: function(title, msg, onStay, onExit) {
            var modal = document.getElementById('portal-guard-modal');
            if (!modal) return;
            document.getElementById('pg-modal-title').textContent = title;
            document.getElementById('pg-modal-msg').textContent = msg;
            modal.style.display = 'flex';

            var btnStay = document.getElementById('pg-btn-stay');
            var btnExit = document.getElementById('pg-btn-exit');

            btnStay.onclick = function() {
                modal.style.display = 'none';
                if (typeof onStay === 'function') onStay();
            };
            btnExit.onclick = function() {
                modal.style.display = 'none';
                if (typeof onExit === 'function') onExit();
            };
        }
    };

    window.PortalGuard = PortalGuard;
    if (document.readyState === 'loading') {
        document.addEventListener('DOMContentLoaded', function() { PortalGuard.init(); });
    } else {
        PortalGuard.init();
    }
})(window, document);
