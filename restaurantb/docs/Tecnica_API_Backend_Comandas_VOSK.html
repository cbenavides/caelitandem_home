5. API Backend (PHP)

5.1. Endpoints de Comandas

POST /api/comanda.php — Registrar nueva comanda
Request
POST /api/comanda.php
Content-Type: application/json

{
    "mesa_id": 5,
    "mesero_id": 3,
    "texto_transcrito": "mesa cinco dos tacos al pastor con todo y una coca",
    "productos": [
        {"producto_id": 12, "cantidad": 2},
        {"producto_id": 45, "cantidad": 1}
    ]
}
Response 200 OK
{
    "status": "success",
    "comanda_id": 1284,
    "total": 145.00,
    "hora_registro": "2026-06-11 14:32:18",
    "tts_mensaje": "Nueva orden: mesa cinco, dos tacos al pastor, una coca.",
    "tts_mesero": "Comanda de mesa cinco enviada."
}
Response 400 Bad Request
{
    "status": "error",
    "mensaje": "Parametros incompletos: se requiere mesa_id y productos"
}
GET /api/comandas/pendientes.php — Listar comandas pendientes
Request
GET /api/comandas/pendientes.php?limite=50
Response 200 OK
{
    "status": "success",
    "total": 12,
    "comandas": [
        {
            "id": 1284,
            "numero_mesa": 5,
            "mesero": "Juan Perez",
            "hora_captura": "2026-06-11 14:32:18",
            "minutos_transcurridos": 4,
            "estado": "pendiente",
            "productos": ["2x Tacos al pastor", "1x Coca-Cola 600ml"]
        }
    ]
}

5.2. Endpoints de Cocina (Voz)

Nota de Separación de Contextos: Los siguientes JSON muestran ejemplos estructurales de los payloads de la API. Para consultar la lista exhaustiva de reglas conversacionales, tiempos de reacción y catálogos de respuestas auditivas (TTS), consulte la Especificación Funcional (Sección 4 y 5).
POST /api/cocina/comando.php — Procesar comando de voz del cocinero
Request
POST /api/cocina/comando.php
Content-Type: application/json

{
    "cocinero_id": 7,
    "texto_dictado": "preparar siguiente"
}
Response 200 OK (comando válido)
{
    "status": "success",
    "accion": "preparar_siguiente",
    "comanda_id": 1284,
    "mesa_id": 5,
    "productos": ["2x Tacos al pastor", "1x Coca-Cola"],
    "tts_respuesta": "Orden de mesa cinco: dos tacos al pastor, una coca. En preparacion.",
    "nuevo_estado": "en_preparacion"
}
Response 200 OK (sin comandas pendientes)
{
    "status": "success",
    "accion": "preparar_siguiente",
    "tts_respuesta": "No hay ordenes pendientes."
}
Response 200 OK (comando no reconocido)
{
    "status": "success",
    "accion": "desconocido",
    "tts_respuesta": "Comando no reconocido. Intente de nuevo."
}

El servidor mantiene un parser de comandos de cocina que analiza el texto dictado mediante expresiones regulares y lo mapea a acciones del sistema:

// Parser de comandos del cocinero (PHP)
$comandos = [
    '/^preparar siguiente$/i'         => 'preparar_siguiente',
    '/^preparar mesa (\d+)$/i'        => 'preparar_mesa',
    '/^listo mesa (\d+)$/i'           => 'listo_mesa',
    '/^recuperar mesa (\d+)$/i'       => 'recuperar_mesa',
    '/^repetir orden mesa (\d+)$/i'   => 'repetir_orden',
    '/^ordenes pendientes$/i'         => 'ordenes_pendientes',
    '/^si,? cancelar$/i'              => 'confirmar_cancelacion',
    '/^no,? no cancelar$/i'           => 'rechazar_cancelacion',
];
GET /api/cocina/estado.php — Estado general de la cocina
Response 200 OK
{
    "status": "success",
    "pendientes": 5,
    "en_preparacion": 3,
    "listas": 2,
    "cancelaciones_pendientes": 1,
    "tts_resumen": "Tienes cinco ordenes pendientes, tres en preparacion y dos listas."
}

5.3. Endpoints de Cancelaciones

POST /api/cancelacion/solicitar.php — Solicitar cancelación (mesero)
Request
POST /api/cancelacion/solicitar.php
Content-Type: application/json

{
    "mesero_id": 3,
    "mesa_id": 5,
    "producto_id": 12,
    "tipo": "parcial"
}
Response 200 OK
{
    "status": "success",
    "solicitud_id": 89,
    "estado": "pendiente_cocinero",
    "tts_mesero": "Solicitud de cancelacion enviada a cocina. Espere confirmacion.",
    "tts_cocinero": "El mesero Juan solicita cancelar tacos al pastor de mesa cinco. Puede confirmar?"
}
Response 200 OK (producto ya listo)
{
    "status": "error",
    "codigo": "producto_listo",
    "tts_mesero": "El producto ya esta listo. No se puede cancelar."
}
POST /api/cancelacion/responder.php — Responder cancelación (cocinero)
Request
POST /api/cancelacion/responder.php
Content-Type: application/json

{
    "cocinero_id": 7,
    "solicitud_id": 89,
    "respuesta": "aprobada"
}
Response 200 OK (aprobada)
{
    "status": "success",
    "accion": "aprobada",
    "tts_cocinero": "Cancelacion autorizada.",
    "tts_mesero": "Cancelacion autorizada por cocina.",
    "tts_altavoz": "Cancelacion autorizada: tacos al pastor de mesa cinco."
}
Response 200 OK (rechazada)
{
    "status": "success",
    "accion": "rechazada",
    "tts_cocinero": "Cancelacion rechazada. Continue preparando.",
    "tts_mesero": "Cancelacion rechazada por cocina."
}
