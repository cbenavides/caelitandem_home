1. Resumen de Producto

El Sistema de Comandas por Voz VOSK es un software industrial y comercial diseñado específicamente para resolver la fricción de captura en el comedor y agilizar el despacho en cocinas de alto tráfico. Mediante el uso de inteligencia artificial en el borde (*Edge AI*) y reconocimiento de voz ejecutándose localmente en el dispositivo, elimina por completo la dependencia del servicio de internet de banda ancha, garantizando un servicio rápido e ininterrumpido en cualquier circunstancia.

Propuesta de Valor Core

  • Cero Costo Operativo de Nube: El motor de transcripción (VOSK WASM) y síntesis (TTS) corre al 100% en los dispositivos del cliente. No se pagan suscripciones a APIs de Google o Azure.
  • Cero Latencia: El reconocimiento de voz y análisis gramatical NLP se procesan localmente en menos de 100ms, acelerando el flujo de comanda en un 40% en comparación con la captura manual.
  • Operación Ininterrumpida: Si el Wi-Fi se apaga, la comanda queda guardada de forma segura en la base de datos interna local (Dexie.js Outbox) y se sincroniza sola en cuanto vuelve la conexión.

2. Módulos Operacionales & Roles

🎙️ Mesero PWA (Push-to-Talk)

Diseñado para smartphones convencionales. El mesero mantiene presionado el micrófono para dictar pedidos estructurados con modificadores (ej. "Mesa 5, 2 tacos al pastor sin cebolla"). Para optimizar la batería y permitir que la pantalla se apague al guardarse el celular, la aplicación detiene físicamente las pistas de audio y cierra el AudioContext al soltar el botón.

🍳 Cocina KDS (Hands-Free)

Estación fija para cocina operada en pantallas de 10". El cocinero controla la bandeja de comandas de forma 100% táctil-libre dictando comandos a su diadema (ej. "Tomo mesa cinco", "Listo mesa cinco"). El software inyecta la API WakeLock para mantener la pantalla permanentemente encendida, asegurando flujo FIFO continuo.

💻 Supervisor / Caja (HTMX)

Panel administrativo con telemetría de red activa. El backend realiza un health-check (Heartbeat) de cada PWA cada 15 segundos. Si un mesero pierde señal por más de 45 segundos, se despliega una alerta visual interactiva con el historial de desconexión del usuario para auditar el desempeño de la red local. [Próximamente / Coming Soon - Fase 5]: Gestión integrada de Reloj Checador para asistencia del personal y módulo de Cortes de Caja (Corte X y Z) para arqueos financieros y conciliación de tickets.

🧠 Motor NLP Local (Fuzzy Correction)

Utiliza el algoritmo de distancia de Levenshtein (umbral de 3 caracteres) ejecutado en cliente para corregir fonemas imprecisos ocasionados por ruido de comedor (ej. corrige "tacos de vastor" a "tacos al pastor") mapeándolos al catálogo original del restaurante de forma instantánea.

3. Especificaciones Técnicas e Infraestructura

La suite de software adopta un enfoque híbrido, combinando simplicidad y robustez para garantizar un despliegue ágil en redes locales estructuradas.

Requisitos Mínimos de Hardware

  • Servidor Local (Appliance): Procesador de 4 núcleos x86, 8 GB de Memoria RAM, 50 GB de almacenamiento SSD. Sistema Operativo Linux (Debian/Ubuntu) o Windows 10 Pro configurado como Appliance.
  • Dispositivos Meseros: Smartphones Android 10 o superior, con navegador Chrome 110+, y diademas inalámbricas o cableadas de cancelación de ruido activa (ANC).
  • Estación de Cocina: Tablets de 10.1" con Android 11+ o mini-PCs industriales con pantalla HDMI, conectadas permanentemente a corriente eléctrica.
