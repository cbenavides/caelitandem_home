Especificación de Arquitectura Técnica: WebApp/PWA Ligera

1. Resumen de la Filosofía del Stack

Esta arquitectura ha sido diseñada bajo la filosofía de máxima eficiencia y baja huella de memoria. Se rechazan los frameworks masivos de servidor (como Laravel o Symfony) y de cliente (como React o Vue). En su lugar, se implementa un ecosistema de micro-librerías independientes y estándares nativos web que garantizan tiempos de respuesta instantáneos, capacidades PWA nativas y una excelente experiencia de usuario (UX).

2. Matriz de Componentes: Qué, Dónde, Por Qué y Cuándo

Componente ¿Qué hace? (Responsabilidad) ¿Dónde ejecuta? ¿Por qué se eligió? ¿Cuándo entra en acción?
PHP 8.3 & Apache 2.4 Entorno de ejecución backend y servidor web tradicional HTTP. Servidor (Backend). Manejo óptimo de recursos en PHP 8.3 y estabilidad probada. En cada petición HTTP síncrona o AJAX inicial.
MariaDB 11 Motor de base de datos relacional. Almacena usuarios y datos de negocio. Servidor (Datos). Rendimiento optimizado para transacciones y Stored Procedures (SP). Cuando el backend requiere persistencia de datos o ejecución de lógica procedural pesada.
Flight PHP Micro-framework de enrutamiento y despacho HTTP (Controlador). Servidor (Backend). Extremadamente rápido y consumo de memoria casi nulo. Al recibir URLs que requieren procesar lógica o renderizar vistas.
Medoo Abstracción de datos para CRUD común y gestor seguro de Stored Procedures (Modelo). Servidor (Backend). Agiliza consultas básicas sin sobrecarga de ORM y expone PDO nativo para orquestar lógica compleja en MariaDB. Para consultas SQL típicas (lecturas/escrituras simples) y como puente de ejecución de procedimientos almacenados complejos.
Plates Motor de plantillas nativo en PHP puro (Vista). Servidor (Backend). Velocidad máxima (sin compilación intermedia) y usa PHP nativo. Cuando el controlador genera fragmentos de HTML para responder.
HTMX Motor declarativo de AJAX, WebSockets y reactividad de interfaz. Navegador (Frontend). Elimina la necesidad de escribir JS o usar jQuery para manipular el DOM y comunicar la red. Al procesar clics, formularios, alertas en tiempo real y flujos seguros de sesión.
