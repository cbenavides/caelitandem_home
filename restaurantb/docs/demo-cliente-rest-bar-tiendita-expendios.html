Resumen: Red Local (LAN) sin Internet

1. Estado del Router (Tenda N301)

  • Modo: Router inalámbrico estándar.
  • Puerto WAN (Azul): Vacío (garantiza que la red sea solo local y sin internet).
  • Acceso a configuración: IP 192.168.0.1 desde el navegador.

2. Estrategia de Direcciones IP

  • Laptop Ubuntu: IP Fija asignada en el router (192.168.0.100). Actúa como servidor central.
  • Dispositivos Android: IP Aleatoria / Automática (DHCP). Actúan como clientes.

3. Pasos para Fijar la IP de la Laptop en el Tenda

  • Paso 1: Obtener la dirección MAC de la laptop en la terminal de Ubuntu con ip link.
  • Paso 2: Entrar a 192.168.0.1, ir a Administración / Lista de clientes DHCP (o Reserva de IP).
  • Paso 3: Vincular la dirección MAC de la laptop con la IP 192.168.0.100 y guardar.
  • Paso 4: Reiniciar el Wi-Fi de la laptop para aplicar el cambio.

4. Aplicaciones para Usar en esta Red

  • Para enviar archivos: LocalSend o KDE Connect (instalados en Android y Ubuntu).
  • Para ver carpetas de la laptop: Compartir carpeta vía Samba en Ubuntu y conectar desde Android usando CX Explorador de Archivos apuntando a la IP 192.168.0.100.
