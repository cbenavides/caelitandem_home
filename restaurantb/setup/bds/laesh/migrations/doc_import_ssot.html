Script de Importación SSOT (Excel a SQL)

Archivo: generate_import_sql.py

¿Qué hace el script?

Este script de Python tiene la responsabilidad de transformar el archivo maestro de Excel (XLSX) proporcionado por el cliente en un archivo SQL ejecutable, para alimentar la base de datos de LAESH como Single Source of Truth (SSOT). Realiza las siguientes operaciones:

  • Lectura de Datos: Utiliza la librería pandas para leer el archivo XLSX, respetando las cabeceras exactas (ej. Tiempo/Días con espacios finales).
  • Depuración: Ignora automáticamente las filas que no tienen asignado un Grupo o área de proceso y convierte los valores nulos (NaN) en cadenas vacías para evitar errores de base de datos.
  • Generación de Entidades Maestras: Genera sentencias TRUNCATE para limpiar los catálogos existentes. Posteriormente, crea un Grupo Raíz (G1) e inserta todas las Categorías únicas extraídas del archivo Excel.
  • Inserción de Estudios: Mapea las columnas del Excel (Clave, Nombre, Muestra, Contenedor, Tiempo, Preparación, Pruebas Incluidas) a sus correspondientes campos en la tabla catalogo_estudios y genera las sentencias INSERT INTO pertinentes.

Fallbacks de Presentación (Website.js)

Cuando la información en la base de datos está vacía, el front-end de la página web (Tooltip de estudios en website.js) implementa cadenas de texto de "reserva" (fallbacks) para asegurar que la interfaz mantenga un aspecto profesional.

  • Clave Interna: Si está vacía, se muestra '—' (guion largo).
  • Tiempo de Procesamiento: Si está vacío, se muestra 'Consultar en LAESH'.
  • Muestra Requerida: Si está vacía, se muestra 'Consultar en LAESH'.
  • Preparación: Si está vacía, se muestra 'Consultar en LAESH'.
  • Contenedor: Si está vacío, se muestra 'Consultar en LAESH'.
  • Pruebas Incluidas: Si está vacío, se muestra 'Consultar en LAESH'.

Nota: Los campos de Contenedor y Pruebas Incluidas han sido homologados para mantener el estándar visual del resto de los atributos.
